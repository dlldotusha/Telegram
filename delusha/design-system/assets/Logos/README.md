# Logos

Знак DelushaGram: буква D целиком из пикселей, сетка 9 × 11, толщина 3 пикселя, скругление пикселя 20%.

- `mark-primary.svg` — основной знак, чернила `#6741b1` (`primary` светлой темы). На светлых фонах.
- `mark-white.svg` — белые чернила, на `primary` и тёмных фонах.
- `mark-scatter.svg` — вариант с разлетающимися пикселями справа, для заставки и экрана «О приложении», не для иконки.
- `app-icon.svg` — иконка приложения 108 × 108 (адаптивная, знак внутри безопасной зоны 66): фон `#4a3290`, знак `#e7ddff`. Для тематической иконки Material You берётся только знак.
- `badge-online.svg` — онлайн-значок 18 × 18: квадрат `#2e9e5b` со скруглением 6, пиксельная D 4 × 5 белым. Ставится на аватар человека, который сейчас в сети с DelushaGram.
