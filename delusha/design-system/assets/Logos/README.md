# Logos

Знак DelushaGram без цвета: только `#1b1b1d`, `#6a6a70`, `#a9a9ae`, белый (на тёмном наоборот). Живой знак в приложении генерируется скриптом и анимирован (компонент Logo); здесь — статичные кадры с seed 7.

- `logo-animated.gif` — как знак живёт: пиксели по одному меняют вид с отскоком.
- `mark-light.svg` — знак для светлых фонов.
- `mark-dark.svg` — знак для тёмных фонов.
- `app-icon.svg` — иконка приложения 108 × 108: фон `#141416`, знак светлыми серыми в безопасной зоне 66. Тематическая иконка Material You берёт этот же знак одним цветом системы.
- `badge-supporter.svg` — значок поддержавшего, серый. Рядом с именем везде.
- `badge-supporter-online.svg` — тот же значок, пока человек в сети: `#2e9e5b`.
- `badge-user.svg` — бейдж пользователя DelushaGram без поддержки: D из серых рамок, только в профиле.
- `badge-online.svg` — в сети с DelushaGram: D белым на `#2e9e5b` в углу аватара.
