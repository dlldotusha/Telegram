# Logos

Знак DelushaGram: буква D целиком из пикселей, сетка 9 × 11, толщина 3, у каждого пикселя свой вид (заливка, рамка, круг, печенька, окно, наложение, половина).

- `mark-varied.svg` — основной знак для светлых фонов: `#6741b1`, `#9a6cf0`, `#1f7a72`.
- `mark-varied-dark.svg` — для тёмных фонов: `#c9b6ff`, `#9a7ff0`, `#7fd6cc`.
- `app-icon.svg` — иконка приложения 108 × 108, фон `#4a3290`, знак в безопасной зоне 66. Для тематической иконки Material You берётся только знак одним цветом.
- `badge-supporter.svg` — значок поддержавшего: D из залитых пикселей `#6741b1` и `#1f7a72` на `#e1d6ff`. Рядом с именем везде.
- `badge-user.svg` — бейдж пользователя DelushaGram: D из рамок `#5d5866` на `#e4e1ea`. Только в профиле.
- `badge-online.svg` — онлайн с DelushaGram: D белым на `#2e9e5b`. В углу аватара вместо точки.
- `mark-primary.svg`, `mark-white.svg` — простой знак из одинаковых пикселей для размеров меньше 24.
