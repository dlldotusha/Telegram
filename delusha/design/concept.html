DelushaGram

Личный форк Telegram для Android. Формы-печеньки вместо кругов, цвет из обоев, пружинная анимация, а всё важное лежит внизу, под большим пальцем.

Тема

На чём держится дизайн

category

Формы

Библиотека форм M3 Expressive: печенье, клевер, цветок. Форма меняется при нажатии и выборе, круги остаются только там, где нужен покой.

palette

Цвет

Monet берёт цвет с обоев на Android 12+, на старых можно выбрать сид вручную. Все цвета это роли M3, никаких захардкоженных синих.

animation

Движение

Пружины вместо кривых: пространственные с отскоком для форм и позиций, эффектные без отскока для цвета. Переходы через SpringAnimation.

text_fields

Шрифт

Roboto Flex с переменной шириной: заголовки широкие и жирные, текст сообщений спокойный. Можно переключить на системный.

back_hand

Одна рука

Навигация, поиск и новые сообщения внизу экрана. Касание минимум 48 dp, свайпы по чатам настраиваются.
