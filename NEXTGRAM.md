# NextGram

Клиент Telegram для Android на основе `DrKLO/Telegram`. Рабочая ветка — `nextgram`.

Что добавлено к Telegram:

- **NextEngine** — кастомизация интерфейса прямо на экране. Зажимаете элемент, меняете его свойства. Правки сохраняются глобально, для категории чатов, для папки или для одного чата.
- **Режим призрака.** Можно не отправлять «прочитано», «в сети», «печатает» и просмотры историй. По умолчанию выключен.
- **Профили для своих.** Расширения профиля (сейчас это частицы в шапке) видят только пользователи NextGram.

Всё собрано в одном экране: **Настройки → NextGram**.

## Релизы

Каждый пуш в `nextgram` запускает `.github/workflows/nextgram-release.yml`:

1. тесты ядра NextEngine и компиляция Kotlin/Java (быстрая проверка);
2. полная сборка APK (`afatRelease`, ABI `arm64-v8a` и `armeabi-v7a`);
3. публикация в **Releases** с версией `0.0.N` (N — номер релиза по порядку; версия Telegram, на которой основана сборка, указана в описании релиза).

Номер сборки входит в versionCode, поэтому каждый релиз ставится поверх предыдущего.

### Секреты репозитория

Задаются в Settings → Secrets and variables → Actions. Без них сборка всё равно пройдёт, но с ограничениями, о которых workflow предупредит.

| Секрет | Зачем | Без него |
|---|---|---|
| `NG_KEYSTORE_BASE64`, `NG_KEYSTORE_PASSWORD`, `NG_KEY_ALIAS`, `NG_KEY_PASSWORD` | своя подпись APK | подпись публичным ключом из исходников Telegram: подписать «обновление» может кто угодно |
| `NG_TELEGRAM_APP_ID`, `NG_TELEGRAM_APP_HASH` | свой api_id с <https://my.telegram.org/apps> | тестовый api_id из исходников, он ограничен на сервере |
| `NG_GOOGLE_SERVICES_JSON` | содержимое `google-services.json` своего Firebase-проекта (package `org.nextgram.messenger`) | FCM-пушей нет |
| `NG_BACKEND_URL`, `NG_BOT_USERNAME` | сервер профилей и бот подтверждения | профили NextGram скрыты |

Ключ подписи создаётся один раз. Если поменять его позже, уже установленный NextGram не обновится, придётся переустанавливать.

```
keytool -genkeypair -v -keystore nextgram.jks -alias nextgram -keyalg RSA -keysize 4096 -validity 36500
base64 -w0 nextgram.jks   # → NG_KEYSTORE_BASE64
```

### Пуши (так рекомендует Telegram)

1. Создайте проект в Firebase и добавьте в него Android-приложение `org.nextgram.messenger`. Его `google-services.json` положите в секрет `NG_GOOGLE_SERVICES_JSON`.
2. На <https://my.telegram.org/apps> укажите для своего api_id FCM-учётные данные этого проекта.

Код приёма пушей уже есть в Telegram. Payload шифруется по MTProto (`secret` в `account.registerDevice`).

## Профили NextGram (сервер)

Сервер — Cloudflare Worker в `backend/worker`, данные лежат в KV. Деплой делает `.github/workflows/nextgram-backend.yml`.

Как сервер узнаёт, что аккаунт ваш: приложение от вашего имени запускает бота командой `/start ng_<nonce>`. Бот видит настоящий `from.id`, который подделать нельзя, и выдаёт токен. Чужие профили запрашивать может только подключённый пользователь, поэтому список пользователей NextGram наружу не уходит.

Настройка, один раз:

1. В @BotFather создайте бота. Нужны его токен и username.
2. В Cloudflare создайте KV namespace и API-токен с правом «Edit Cloudflare Workers».
3. Добавьте секреты: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `NG_KV_ID`, `NG_BOT_TOKEN`, `NG_BOT_USERNAME`, `NG_WEBHOOK_SECRET` (любая случайная строка), `NG_BACKEND_URL` (например `https://nextgram-profiles.<subdomain>.workers.dev`).
4. Запустите workflow «NextGram backend» вручную (Actions → Run workflow). Он задеплоит воркер и настроит вебхук бота.
5. Пересоберите APK, чтобы в него попали `NG_BACKEND_URL` и `NG_BOT_USERNAME`.

Тест сервера без Cloudflare: `node backend/worker/test.mjs`.

Тесты ядра NextEngine: `KOTLINC=kotlinc JSON_CP=json.jar ./nextengine-tests/run.sh`.

## NextEngine

Весь код NextGram написан на Kotlin (плагин `org.jetbrains.kotlin.android` подключён в `TMessagesProj`). Апстримный Java-код Telegram вызывает его через `@JvmStatic`.

```
TMessagesProj/src/main/java/org/nextgram/
  engine/core/   модель, уровни, каскад, JSON (без Android, тесты в nextengine-tests/)
  engine/        загрузка/сохранение (NextEngine), уровни чата, цвета темы, строки
  engine/edit/   режим редактирования: оверлей, хит-тест, заготовки, панель, пикер
  engine/hooks/  хуки для апстримных классов
  ghost/         режим призрака
  profiles/      профили для своих: клиент, частицы, хук профиля
  ui/            экран «NextGram» в настройках
```

**Уровни** (от общего к частному): везде → категория (контакты / не контакты / группы / каналы / боты, как в папках Telegram) → папки (верхняя в списке важнее) → конкретный чат. Слияние идёт по свойствам, а не по элементам целиком.

**Заготовки.** Элемент разобран на части так, как их видит человек (у сообщения — пузырь, текст, имя, ответ, время; у чата в списке — аватар, название, превью, время, счётчик). Зажали часть — открываются её свойства: цвета, размер текста, а где есть — настройки по уровням. Свойства с понятными названиями: «Фон пузыря», «Цифры счётчика», «Подсказка „Сообщение“» и так далее. Цвет и прозрачность настраиваются в одном окне, с подписанными ползунками. Готовые заготовки (`engine/edit/ThemeCatalog.kt`):

- сообщение (входящие и исходящие отдельно): пузырь, текст, ссылки, ответы, время, галочки, файлы, голосовые; у времени дополнительно секунды, свой цвет и скрытие по уровням;
- чат в списке: название, превью, время, счётчики, значки, фон;
- служебные плашки (даты, события), поле ввода сообщения, верхняя панель, нижние вкладки, шапка профиля;
- все пункты настроек: текст, значения, иконки, переключатели, заголовки и пояснения разделов.

Для элементов без заготовки показываются цвета темы, найденные на экране, с названиями, собранными из имени ключа.

**Цвета темы общие.** Если поменять, например, цвет акцентной кнопки, он изменится везде, где Telegram его использует, в том числе на экранах NextGram. Цвета сохраняются отдельно для каждой темы и не трогают файл темы.

**Интерфейс NextGram** собран на родных компонентах Telegram: `UniversalFragment`/`UItem`, `BottomSheet`, `TextColorCell`, `AlertDialog`. Плавающая панель режима правки берёт цвета из темы, её можно перетащить за любое место и свернуть в кнопку.

**Как добавить заготовку:**

- только цвета — одна запись `CatalogSpec` в `ThemeCatalog.specs`: как узнать элемент (класс view) и какие цвета с какими названиями показать;
- со своими свойствами по уровням — класс `EditorSpec` (части с границами и свойства), строка в `SpecRegistry` и однострочные хуки в апстримном классе, которые читают `NextEngine.resolve(account, dialogId, elementId)`.

Конфиг лежит в `files/nextengine.json` внутри данных приложения.

## Правки в апстримных файлах

Все правки помечены `// nextgram`, поиск: `git grep -n "nextgram" -- TMessagesProj/src/main/java/org/telegram`. Обновление до новой версии Telegram — это мердж апстрима в `nextgram`; конфликты будут только в этих строках.

| Файл | Что |
|---|---|
| `tgnet/ConnectionsManager.java` | фильтр режима призрака |
| `ui/Cells/ChatMessageCell.java` | время: секунды, цвет, скрытие, границы для редактора |
| `ui/ActionBar/Theme.java`, `ThemeDescription.java` | переопределение цветов темы, геттеры |
| `ui/LaunchActivity.java` | касания для режима редактирования |
| `ui/SettingsActivity.java`, `ui/ThemeActivity.java` | пункты меню |
| `ui/ProfileActivity.java` | слой частиц в шапке |
| `messenger/BuildVars.java`, `TMessagesProj/build.gradle` | api_id и адрес сервера из `local.properties` |
| `TMessagesProj_App/build.gradle`, `gradle.properties` | ABI и номер сборки из CI, package `org.nextgram.messenger` |

## Ограничения

- Режим призрака нарушает п. 1.4 правил Telegram API. Со своим api_id это риск отзыва ключа. Сервер помечает чат прочитанным, когда вы отправляете в него сообщение. Непрочитанные могут вернуться после повторной синхронизации диалогов с сервером.
- В каналах время скрывается вместе с подписью автора: Telegram рисует их одной строкой.
- В чатах со своей темой её цвета перекрывают изменённые цвета темы.
- Сэмплов для элементов, которых нет на экране, пока нет.
- Размеры текста общие для всего приложения (так устроены кисти Telegram): сообщения (та же настройка, что «Размер текста» в «Оформлении»), время, имя, ответ, служебные плашки, список чатов. Размер текста в пунктах настроек пока не меняется.
- Иконка NextGram: N со стрелкой; на Android 12+ стрелка берёт системный акцент (Material You), фон и цвет N следуют светлой/тёмной теме, на Android 13+ есть монохромный слой.
